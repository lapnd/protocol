# Sample prompts

Copy a prompt, fill in the `<…>` parts, and paste it into Claude Code (or
another AI agent) running in this repo. The prompts lean on the skills in
`.claude/skills/`:

| Skill | Use it to |
|---|---|
| `explainer-author` | write a new explainer or lesson on any topic |
| `explainer-review` | check accuracy, teaching quality, translations and visuals |
| `explainer-visual` | build a custom visual, or plug in a bespoke system like Protocol Explorer |

| File | When |
|---|---|
| [01-new-explainer.md](01-new-explainer.md) | Create a topic from scratch |
| [02-from-source.md](02-from-source.md) | Turn an article, notes or a PDF into an explainer |
| [03-add-lesson.md](03-add-lesson.md) | Add a lesson to an existing topic |
| [04-review.md](04-review.md) | Review and fix |
| [05-translate.md](05-translate.md) | Add a language |
| [06-custom-visual.md](06-custom-visual.md) | Show something the built-in visuals can't |
| [07-custom-system.md](07-custom-system.md) | Plug in a separate app, like Protocol Explorer |

Tip: the more specific you are about the **learner** and the **scope**, the
better the result.
