# Turn a source document into an explainer

```
Use the explainer-author skill. Here is the source material: <paste text / file path / URL>.

Turn it into an interactive explainer:
- id: <id>, locales: en, vi
- Stay faithful to the source. Where it is vague or may be out of date, flag
  it and ask me instead of inventing anything.
- One idea per lesson; pick the right visual for each.
- Add a quick check on the most important idea of each lesson.
- List this document in sources.
- Run npm run check, then summarize.
```
