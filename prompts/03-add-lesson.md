# Add a lesson to an existing explainer

```
Use the explainer-author skill. Add a lesson to the "<id>" explainer
(src/explainers/<id>/).

New lesson: <e.g. "Rebase vs merge">
Position: after lesson "<lesson-id>", in group "<group-id>"
Reuse the running example, colors and terms of the existing lessons (read them first).
Suggested visual: <diagram with moving pointers / sequence / …>
Translate into every locale in `locales`. Run npm run validate and fix all warnings.
```
